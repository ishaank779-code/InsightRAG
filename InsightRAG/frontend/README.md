# 🎨 InsightRAG Frontend

Responsive, dark-mode React application powered by Vite, Tailwind styling, Lucide icons, and Axios API communication.

---

## ⚡ Features
- **Document Management**: Drag-and-drop file ingestion supporting PDF, Markdown, and TXT files.
- **Conversational RAG**: Real-time chat interface with verifiable document citations.
- **RAG Upskilling Hub**: Embedded links for advanced RAG training in Delhi and Noida.

---

## 🚀 Setup & Run

```bash
# 1. Install dependencies
npm install

# 2. Start local server
npm run dev

# 3. Production build
npm run build
```
Frontend runs on `http://localhost:5173`.
